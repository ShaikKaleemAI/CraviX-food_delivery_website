Order closing time

Customers can only place orders up to this time each day. After it passes (plus any extra time you allow below), ordering is disabled until the next day.

Current setting: 7:15 PM

Extra time after closing

A short grace window that still lets customers place an order right after the official closing time. Orders — and cancellations — are blocked once this window ends.

Current setting: 3 minutes

Minimum order pool

Each day, orders are held as "Pending" until the combined value of everyone's orders reaches this amount. The order that crosses the line confirms itself and every pending order from that day, all at once — so the kitchen only starts once there's a worthwhile batch.

Current setting: ₹600

Cancellation window

Choose how customers' cancellation deadline is decided for the day. Only one method applies at a time.

How many extra minutes customers can still cancel an order for, counted from the moment ordering fully closes for the day (Order Closing Time + Extra Time After Closing). This is the same deadline for every order that day — not measured from when each person individually placed theirs.

Example: closing 7:30 PM + 3 min extra time + a 10 min cancellation window here = customers can cancel any of today's orders up until 7:43 PM.

Customers can only cancel an order while the clock is inside this daily window — regardless of when their order was placed or when the kitchen closes. Before it opens or after it closes, cancellation isn't allowed.

Current setting: 15 minutes
